Database setup

Setup mode is enabled. Opening this page does not run setup. Submit the existing application secret to create missing tables and apply supported upgrades for schema v{{ schema_version }}.

Back up your database first. This is not a backup import tool and does not automatically repair missing AUTO_INCREMENT on existing columns such as password_otp.id.

Use SECRET_KEY from your existing .env, not OWNER_BOOTSTRAP_KEY. Do not change it or share it. The key is submitted in the POST body, never the URL.

When finished, set SETUP_ENABLED=false in .env and restart or redeploy.
